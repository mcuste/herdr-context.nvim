1. Overview                                         *herdr-context-overview*

herdr-context.nvim places the current saved file or visual line range in a Herdr
agent's input and focuses that agent. It does not submit the input.

The plugin requires Neovim 0.10 or later and Herdr 0.7.5 or later. Neovim
must run inside a Herdr pane with $HERDR_WORKSPACE_ID and $HERDR_TAB_ID set.

The plugin prefers agents in the current tab and falls back to agents elsewhere
in the workspace. Several candidates open |vim.ui.select()|. It does not write
buffers.

=============================================================================
2. Setup                                               *herdr-context-setup*

Call setup once: >lua

  require('herdr-context').setup({
    mappings = {
      buffer = '<leader>ac',
      selection = '<leader>ac',
    },
  })
<
The default configuration is: >lua

  {
    mappings = {
      buffer = '',
      selection = '',
    },
  }
<
The empty default mapping leaves the user's key space unchanged.

=============================================================================
3. Commands                                         *herdr-context-commands*

:HerdrContextSendBuffer                 *:HerdrContextSendBuffer*
    Send the current saved file to a Herdr agent.

:HerdrContextSendSelection           *:HerdrContextSendSelection*
    Place the current visual selection in a Herdr agent's input. The command
    accepts the Ex range generated by Visual mode.

=============================================================================
4. Lua API                                               *herdr-context-api*

setup({config})                            *herdr-context.setup()*
    Apply configuration, create the command, and create the optional mapping.

send_buffer()                         *herdr-context.send_buffer()*
    Send the current saved file reference.

send_selection()                   *herdr-context.send_selection()*
    Send the current saved file reference with an inclusive line range. A
    whole-line selection sends only the reference. A partial-line or block
    selection also appends the exact content as a fenced code block.

    Adapter formats for lines 18-42:

    - OMP and Pi: ` @path#L18-42 `
    - Claude Code: ` @path#18-42 `
    - Codex: ` path Lines 18-42. `
    - Unknown kinds: ` @path Lines 18-42. `

    Buffer references omit the range suffix. Codex uses a plain path. Every
    reference has one leading and one trailing space.

    Full-buffer and whole-line operations reject unsaved changes. Partial
    selections include current buffer content and remain exact when modified.

    Both functions prefer agents in the current tab. If that tab has no
    agents, all agents in the workspace are considered. Several candidates
    open |vim.ui.select()|.

    Picker rows contain the tab label, harness name, lifecycle state, and
    working directory. Duplicate harness types in one tab include the pane ID
    used to place input and focus. A custom |vim.ui.select()| implementation
    can provide fuzzy matching.

    The plugin never submits the inserted text. Add context or edit it before
    pressing Enter.

    The functions report an error and send nothing when:

    - The buffer has no file on disk.
    - A full-buffer or whole-line operation has unsaved changes.
    - Herdr is unavailable.
    - The Herdr workspace or tab environment is missing.
    - The workspace has no agents.
    - The selected agent is blocked.

=============================================================================
5. Health                                             *herdr-context-health*

Run: >vim

  :checkhealth herdr-context
<
The check reports the Neovim version, Herdr version and availability, Herdr
environment variables, and the agent and tab list status.
